# Testing Baseline

This document is the canonical list of the project's verification tiers and
required Go gates. Run commands from the repository root. Wall times are the
current reference measurements, not budgets, unless a target is stated.

| Tier or gate                          | Command                                                                                   | Current wall time                                                         | Purpose and when to run                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| ------------------------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Fast suite                            | `make test-fast`                                                                          | 23s, target <=30s                                                         | Everyday confidence check before every handoff. Runs all Go packages in short mode, with the existing `testing.Short` guards, once and without the race detector.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| E2E smoke shell                       | `bash test/e2e/smoke.sh`                                                                  | 48.53s                                                                    | Builds the binary and checks CLI flags and embedded skill layout. Run when launch behavior, embedded skills, or release packaging may be affected.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Isolated integration                  | `go test ./test/integration/... -count=1`                                                 | 323.06s                                                                   | Covers lifecycle, state-machine, runs-layout, and protocol-violation behavior. Run when those cross-component paths change.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| E2E Go (process-launch / API-driven)  | `go test ./test/e2e/... -count=1 -race`                                                   | 41.51s                                                                    | Exercises server process launch, API behavior, and session lifecycle with the race detector. Run when those boundaries change.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Race regression                       | `go test ./... -count=1 -race`                                                            | 158.82s                                                                   | Extended all-package race and regression sweep. Run before merging high-risk or concurrency-sensitive changes; this is not the everyday unit command.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Live Codex compatibility | `AGENTIC_CODEX_LIVE=1 go test ./test/e2e -run '^TestCodexContractLive$' -count=1 -timeout=20m -v` | ~2–3m for two models | Opt-in authenticated inference: structured questions, artifact rejection/repair, fresh threads, and cross-model resume. Run when changing the Codex CLI baseline, model catalog, instruction delivery, or tool protocol. See [Codex phase contract](codex-contract.md). |
| Desktop static checks                 | `npm run check`                                                                           | 8s                                                                        | Runs TypeScript checks, ESLint, Prettier verification, desktop OpenAPI drift detection, and the canonical error-markup guard. Run for desktop source, tooling, formatting, or API-contract changes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Desktop unit/component/security tests | `npm test && npm run test:security`                                                       | 4s                                                                        | Runs the Vitest renderer, main-process, shared-code, script, and security projects, followed by the explicit security-project gate used by CI. Run for desktop behavior, IPC, preload, policy, or packaging-script changes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Desktop packaged E2E                  | `npm run package:verify && npm run test:e2e:packaged`                                     | ~10m full suite; ~1-2m per targeted spec after the one-time package build | Builds and inspects the native unsigned package, then drives the packaged Electron app and its bundled Go server through the Playwright journey suite. The journeys cover supervision and launch, feature lifecycle and attention flows, planning and review recovery, configuration and workspace restart, history and rewind, publishing and retry behavior, distribution updates, diagnostics, and production security posture. Run for end-to-end desktop workflows, main/server integration, packaging, or distribution behavior — and for **any renderer change that alters user-visible text, roles, or aria-labels**, since the journeys assert on those (see AGENTS.md). Runs locally; scope to the affected specs with `npm run test:e2e:packaged -- test/e2e/journeys/<spec>.spec.ts -g "<test title>"`. On macOS, `npm run e2e:cleanup-handlers` lists (and with `--apply` unregisters) stale `agentico:` URL-handler claims left by old test, build, or dev copies of the app; it is a manual, one-off tool that rewrites LaunchServices claims and can trip endpoint-security monitoring, so it is deliberately not part of any automated step. |
| Desktop release audit                 | `npm run audit:release --workspace desktop && npm run release:verify --workspace desktop` | Local/static                                                              | Checks dependency licenses and provenance, lockfile and module integrity, desktop protocol and hardened-runtime configuration, digest-pinned Linux toolchains, the local `make release` ordering, GoReleaser target/manifest configuration, and updater Ed25519 trust-root semantics. `make release` additionally performs machine/credential/image preflight and post-build provenance rechecks. Run for dependency, packaging, signing, or release-pipeline changes.                                                                                                                                                                                                                                                                                                                                              |
| Go static-analysis gate               | `go vet ./...`                                                                            | Not separately recorded                                                   | Required static analysis for all changes; run before push and whenever Go code or generated Go output changes.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Go build gate                         | `go build ./...`                                                                          | Not separately recorded                                                   | Required compilation check for all Go packages; run before push and whenever Go code, generated Go output, or build inputs change.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |

The fast suite intentionally omits the race detector. Use the named extended
tier that matches the changed area, and record the tiers run in the PR
description.
