# Agentic Orchestrator User Guide

Quick-reference index for Agentic Orchestrator users. The Electron desktop app is the primary interface; `agentico` is its local server and administration CLI, not the desktop application binary.

The guide describes only labeled controls delivered in the current Electron app. When a workflow-engine capability is not yet available in the app, its topic marks it **pending** instead of presenting retired terminal-client instructions.
