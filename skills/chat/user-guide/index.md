# Agentic Orchestrator User Guide

Quick-reference index for Agentic Orchestrator users. The Electron desktop app is the primary interface; `agentico` is its local server and administration CLI, not the desktop application binary.

The guide describes labeled controls delivered in the Electron app. Each topic covers the runtime semantics and the desktop controls that expose them.
